STRATOS – Special Coin v1
=========================

Standalone special collectible sprite pack.

Main in-game strip:
- game_scale_40/special_coin_spin_8f_40x40.png
- Horizontal strip, 8 frames, each 40x40 (total 320x40).

Alternative:
- game_scale_64/special_coin_spin_8f_64x64.png
- Horizontal strip, 8 frames, each 64x64 (total 512x64).

Individual frames are available in frames_40/ and frames_64/.

Godot import:
- Filter: Nearest
- Mipmaps: Off
- Repeat: Disabled
- Compression: Lossless
- Preserve transparency.

Animation setup:
- Hframes: 8
- Vframes: 1
- Frame size: 40x40 when using the game_scale_40 strip.
- Suggested animation speed: 6–8 FPS.
- Keep animation scale stable; do not add bloom or strong glow.

The sprite is intentionally distinct from the standard gold coin:
a turquoise faceted gemstone within a gold/brass frame.
No pickup effects or scripts are included.
